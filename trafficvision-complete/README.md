# TrafficVision Complete

A self-contained React + Vite demo implementation inspired by the supplied TrafficVision source.

## Run

```bash
npm install
npm run dev
```

Then open the URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Important

The project intentionally uses demo camera metadata and representative public images. It does not claim to contain the original site's private backend, 155,000-camera database, proprietary APIs, Firebase credentials, or licensed live feeds.

To use real feeds, replace the camera records in `src/main.jsx` with feeds you are authorized to display and add your own backend/API layer.

## Demo premium password

`trafficvision`

This password is only a frontend demo gate and is NOT secure authentication. Use Firebase/Auth or a server-side session for real premium access.
